Service End of Life

Walltaker Favorites Widget has reached the end of it's life, and will be fully shut down on February 6th, 2027.

If you have any widgets on your Walltaker profile backups (or anywhere else), I strongly advise you to remove all of them, as they will become prone to hijacking after the full shutdown.

The project's source code is now public domain. If you really care about it, please fork or download the source code from the GitHub repository, as the repo may be deleted in the future.

Thank you for everything.

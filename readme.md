# Walltaker Favorites Widget

A widget for Walltaker that lets you display a random selection of posts from your e621 favorites. The posts are randomized everytime the widget is loaded.

⚠ This is a very rough prototype. Widgets generated right now may stop working in the future.

## Features

- You can apply custom width and height to the widget to the iframe via CSS, and everything should still display correctly.
- You can click on the images to copy the e621 link to your clipboard

## Deploying
Everything is done client-side with JS, and the posts are pulled directly from e621. Any web server than can serve files will work.
